## Summary of the Fix

DataStore silently skips incoming subscriptions when the GraphQL response contains errors — typically caused by a mutation performed **outside of DataStore** (e.g. a direct GraphQL mutation to AppSync) that doesn't request all the fields DataStore needs to sync. Previously, this only logged a terse, unhelpful warning:

```
DataStore - Skipping incoming subscription. Messages: Cannot return null for non-nullable type
```

This caused repeated confusion in the Amplify community, with developers unable to self-diagnose the root cause.

### Change made
Updated the warning message in `packages/datastore/src/sync/processors/subscription.ts` to explain the likely cause and point developers toward the relevant documentation, while preserving the original error messages for debugging.

**File changed:** `packages/datastore/src/sync/processors/subscription.ts`
**Type of change:** Text-only (no logic changes) — improves the `logger.warn` message triggered when a subscription is skipped due to GraphQL errors.
