# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose users or downstream systems. Use GitHub's private vulnerability reporting for this repository when available.

Include the affected version, a minimal reproduction, impact, and any suggested remediation. Do not include real credentials, private contracts, or customer data.

## Security boundary

Agent Action Contract is a declaration validator, not an authorization or sandbox enforcement system. A clean lint result does not prove runtime compliance. Consequential actions still require enforcement outside the model and independent verification of evidence.
